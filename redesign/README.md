# «Слопай букет»: премиальный редизайн

Статичный сайт на HTML, CSS и JS без сборки. GSAP 3.12.5 (ScrollTrigger, Flip), Lenis 1.1.13 и Swiper 11.1.14 лежат в `vendor/`, поэтому сайт не зависит от CDN.

```
redesign/
├── index.html          разметка всех 20 блоков, SEO, JSON-LD LocalBusiness
├── css/style.css       дизайн-система: цвета, шрифты, адаптив, reduced-motion
├── js/app.js           логика и анимации; выключатели фишек в FEATURES
├── js/data.js          каталог (129 работ) и отзывы; генерируется из content/*.json
├── tools/build-data.py пересборка data.js
├── vendor/             GSAP, Lenis, Swiper
└── img → ../public/img симлинк на реальные фото мастерской
```

## Запуск

```bash
cd slopay-buket
python3 -m http.server 8080
# открыть http://localhost:8080/redesign/
```

Корень сервера должен быть корнем репозитория: тогда работают симлинк `img` и ссылки на `../privacy/` и `../oferta/`.

### Выкладка на сайт

Включено: при каждом сохранении в `main` GitHub Pages собирает сайт как раньше, а затем шаг «Новая главная» (`python3 redesign/tools/install.py dist`) ставит эту главную вместо старой. Политика, оферта, страница для компаний, страницы категорий, sitemap.xml, robots.txt и фото остаются из прежней сборки. Яндекс Метрика (с теми же целями) и подтверждение Google перенесены.

Откат на старую главную: удалить шаг «Новая главная» из `.github/workflows/pages.yml`.

### Обновление каталога

Цены, названия и видимость работ правятся, как и раньше, в админке (`content/products.json`). При выкладке `data.js` пересобирается автоматически. Для локального просмотра после правок:

```bash
python3 redesign/tools/build-data.py
```

Количество работ и цены «от» в категориях, мега-меню и полноэкранном меню считаются из данных автоматически.

### Как устроена отправка заказа

Оплаты на сайте нет. Все кнопки собирают текст заказа (букеты со ссылками на фото, итог «от», дата, время, адрес, записка, «анонимно»). К тексту, как и на текущем сайте, добавляется метка «(с сайта)».

- **Telegram:** ссылка `t.me/+79631282556?text=…` открывает чат с Марией, текст уже вставлен в поле ввода.
- **MAX:** MAX не умеет принимать текст в ссылке, поэтому текст копируется в буфер, открывается профиль, а тост просит вставить сообщение.
- **Форма с фото на телефоне:** если браузер умеет делиться файлами, открывается системное «Поделиться» с фото и текстом. На компьютере текст уходит в мессенджер, а фото клиент прикрепляет в чате.

### SEO и доступность

- Один `h1`: «Съедобные букеты в Ульяновске — подарок со вкусом».
- `title`, `description`, `canonical`, Open Graph и Twitter Card (картинка `og-image.jpg` из текущего сайта).
- JSON-LD `LocalBusiness`/`Florist`: адрес, часы, телефон, рейтинг 5,0 и 107 отзывов. Список `Product` для 6 хитов добавляет скрипт (`seoProducts()`). Если нужна разметка без JS, перенесите её в `index.html` статикой.
- Семантика (`header`, `nav`, `main`, `section` с `aria-labelledby`, `footer`, `address`, `details`), skip-link, видимый фокус.
- Панели: `role="dialog"`, `aria-modal`, фокус-ловушка, закрытие по Esc, клику на фон, крестику и свайпу. Прокрутка страницы на это время блокируется.
- Контраст на фоне `#0a0908`: основной текст `#f3e9dc` (~16:1), вторичный `#b3a594` (~8:1), подписи `#8a7e71` (~5:1), кремовый на малиновой кнопке (~5.7:1), все пары проходят WCAG AA.
- Фото: WebP, `loading="lazy"`, `decoding="async"`, размеры заданы; первая картинка hero загружается заранее (preload). Анимации меняют только `transform` и `opacity`. Исключение — `clip-path` у шторки, как и просили в ТЗ.

### Проверено

Chromium (Playwright): 1440×900 и iPhone 13. Ошибок в консоли нет, горизонтальной прокрутки нет. Работают корзина, быстрый просмотр, квиз, шторка фильтров, полноэкранное меню, мега-меню и режим reduced-motion. Вёрстка рассчитана на брейкпоинты 360 / 768 / 1024 / 1440 / 1920.

## Что сейчас на заглушках

1. **Портрет Марии.** В блоке «Кто собирает» стоит плейсхолдер с описанием кадра.
2. **Фото увядших роз в сравнении** (`img/wilted.webp`) — иллюстрация из текущего сайта. Лучше заменить своим кадром (см. шот-лист, п. 6).
3. **Слои параллакса в hero** — векторные ягоды, роза и листья. После съёмки вырезанных ингредиентов (п. 2) их можно заменить фотографиями.

## Шот-лист: какие фото подготовить

Общие правила: тёмный фон (графит, чёрный бархат, тёмное дерево), тёплый боковой свет слева или справа, без вспышки, без бутылок и банок с алкоголем в кадре. Сохранять в WebP: 1100 px по длинной стороне для крупных фото и 440 px для превью. Сейчас почти все работы сняты на светлом фоне, поэтому на тёмном сайте они смотрятся как вставки. Пересъёмка хитов на тёмном даст самый заметный прирост.
