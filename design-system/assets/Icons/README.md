# Icons

The site's own messenger marks (`src/components/shared/icons.tsx`), 24px viewBox, one filled path each.

- `max.svg` — MAX messenger. On `color-max` buttons, white.
- `telegram.svg` — Telegram paper plane. On `color-tg` buttons, white; `#1477a8` on the outline variant.
- `vk.svg` — VK, shown in the footer only when a VK link is set.

Single ink: the files are stored in black; on the site they inherit the text colour (white on messenger buttons). Interface icons come from lucide-react and are not stored here.
