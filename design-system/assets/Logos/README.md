# Logos

- `logo-emblem-512.png` — the master emblem, 512×512 PNG with transparent corners (`assets-src/`). Use for print and large placements.
- `logo-256.webp` — 256px web version used in the site header and footer.
- `apple-touch-icon.png` — 180px home-screen icon.
- `favicon-64.png` — 64px favicon.

Full-colour raster marks: place on `color-cream` / `color-surface` in either theme; never on gold, never recoloured.

In the repository the files themselves live at `assets-src/logo-emblem-512.png`, `public/logo-256.webp`, `public/apple-touch-icon.png` and `public/favicon-64.png` — not duplicated here.
